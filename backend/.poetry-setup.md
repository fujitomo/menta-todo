# Poetry セットアップ手順

## 初回セットアップ

1. **Poetry のインストール**（まだインストールしていない場合）

   ```bash
   # Windows (PowerShell)
   (Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -

   # macOS/Linux
   curl -sSL https://install.python-poetry.org | python3 -
   ```

2. **poetry.lock ファイルの生成**

   ```bash
   cd backend
   poetry lock
   ```

   これにより、`pyproject.toml`から`poetry.lock`ファイルが生成されます。

3. **依存関係のインストール**

   ```bash
   poetry install
   ```

## 依存関係の管理

### パッケージの追加

```bash
poetry add <package-name>
poetry add <package-name>==<version>  # 特定のバージョンを指定
```

### パッケージの削除

```bash
poetry remove <package-name>
```

### 依存関係の更新

```bash
poetry update  # すべてのパッケージを更新
poetry update <package-name>  # 特定のパッケージを更新
```

### requirements.txt の生成（必要に応じて）

```bash
poetry export -f requirements.txt --output requirements.txt --without-hashes
```

## Docker での使用

Dockerfile は既に Poetry を使用するように設定されています。
`poetry.lock`ファイルをコミットすることで、一貫した環境を保つことができます。
